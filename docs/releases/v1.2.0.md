# 灵音 v1.2.0

正式版名称为「灵音」，版本号 `1.2.0`（versionCode 12），使用固定发布签名，包名恢复为 `com.salt.music`。

## 安装前请先看

- 本版与椒盐音乐使用相同包名，不能同时安装；灵音与椒盐音乐及 vivo 无关联。请勿直接卸载已有应用来尝试安装。
- 从 `com.auramusic.app` 或「灵音预览」迁移时，两版可以保留，但数据不会自动共享。先导出/备份歌单并保留原插件及配置，再迁移数据。
- 手机上的「灵音·原子岛测试」使用 debug 签名，不能直接覆盖为本正式签名包。应先完整备份并确认数据迁移，切勿先卸载。
- 旧 beta 的版本比较存在问题，可能不提示此正式版更新；请从本 Release 手动下载 APK。本版已修正后续版本比较。

## 本版变化

- 浅色线条图标；推荐、搜索、播放队列、音质面板及按钮使用统一玻璃材质与按压过渡；歌曲列表增加分隔和折射背景。
- 切歌时封面背景交叉渐变，修复小屏、横屏、安全区和操作区遮挡。
- 网易云歌单按完整歌曲 ID 分批读取，修复只导入首批、重复歌单卡片、首曲封面与重试覆盖问题；平台只提供部分数据时明确报告未完整。
- 本机歌单支持批量移除歌曲，数量和首曲封面同步更新；保留空歌单，重新导入不会默默恢复用户删除的内容。
- 保留实际可用的播放、音质、动效与透明度设置；音质档位标注依据音源提供信息，不等于逐项验证可播放。
- 恢复历史包名后，已在 vivo X200 Pro mini / OriginOS 6 验证原子岛显示和基础播控。其他设备/ROM 及厂商扩展能力范围见[兼容性说明](../originos-compatibility.md)。
- 正式包关闭 WebView 调试，修正 beta 与正式版的更新比较。

## 安装包校验

发布前检查：31 个数据/功能测试、17 组浏览器场景，以及 Release 构建与 lintRelease 均通过。原子岛证据来自相同媒体代码的旧包名 debug 真机对照；本次正式签名 APK 未覆盖手机上的 debug 测试版。
