# 灵音 v1.3.2 · 真实液态玻璃与流光重构

本版迎来视觉与交互质感的全面跃迁，深度重构全域真实液态玻璃（Liquid Glass）光学拟态，彻底告别单调灰暗与生硬边缘，带来媲美 Apple Music 与 vivo OriginOS 7 的沉浸式水光体验。

### 真实液态玻璃（Liquid Glass）光学质感跃迁
- **WebGL 三通道物理透镜色散（Chromatic Dispersion）**：基于 GPU 片元着色器与曲面法线场，实现红、绿、蓝三波长非均匀折射位移采样。控件与卡片边缘呈现真实的彩虹折射微光与水珠透镜景深。
- **活态四维极光背景（Aurora Mesh）**：全屏注入天青（Cyan）、电紫（Violet）、晚霞珊瑚（Coral）与清新薄荷（Mint）的动态弥散流光，并伴随水波涟漪扩散；彻底去除底层实色遮蔽，通透折射底层光影。
- **流体粘性非对称挤压动效（Fluid Viscosity & Q-Bounce）**：按下时模拟水滴张力发生横向展开与纵向压扁的非等比体积微形变，释放瞬间带有 1.45 倍超调弹簧回弹抖动，触感极具生命力。
- **黑胶唱片原光流体底座**：播放大页黑胶唱片置于高光水波光池之上，伴随音乐节律自适应呼吸收放；进度滑轨升级为内嵌流槽与高光水银圆珠。
- **专辑流光次表面融合**：模糊背景与底层极光网格通过柔光融合算法自然混色，让每首歌曲呈现专属且饱满的动态色相氛围。

### 播放稳定性与交互缺陷彻底修复
- **时钟心跳生命周期自愈**：修复从息屏或后台切回前台后，播放进度轮询未自动复活导致的假死停更 Bug；优化后台切歌时的异步网络保活机制。
- **歌词手势全域安全捕获**：修复滑动歌词滑出容器边缘或触发系统边缘手势时触摸状态死锁导致的永久停滚问题；切歌时自动复位手势拦截态。
- **切歌即时乐观归零**：切歌第一帧即时重置进度滑轨、滑块与时间标签，消除换源解析期间上一首歌曲尾部进度的视觉停滞。
- **横屏/车机一体化底盘重构**：严密锁定横屏全屏播放器视口，彻底消除横屏模式下的意外纵向滚动条以及进度条与背景分离的体验断层。
