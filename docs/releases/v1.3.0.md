# 灵音 v1.3.0

本版加入应用内增量更新，继续使用 `com.salt.music` 和固定正式签名。

- 界面资源支持独立更新，下载后刷新页面即可应用，无需安装 APK。
- 原生升级支持 APK 差分还原，校验失败自动回退完整安装包。
- 设置中的检查更新支持下载进度、取消、续传、重试和系统安装确认，使用液态玻璃样式的更新面板。
- 更新清单加入数字签名，下载文件逐项校验；网页资源启动失败时可回退上一版本。
- 首次启动自动备份并迁移歌单、收藏、队列、音源和偏好，保持现有数据。

**从 v1.2.1 或更早版本升级，本次仍需完整 APK 覆盖安装**，之后发布的兼容更新才可使用新机制。APK 差分减少下载量，最终仍须按 Android 提示确认安装；界面更新无需安装。GitHub 网络本身的速度限制仍然存在。

请直接覆盖升级，不要卸载现有应用。相同包名但调试签名不同的安装不能直接覆盖，需先保留数据并处理签名迁移。

发布维护方式见[增量更新说明](../incremental-updates.md)。
