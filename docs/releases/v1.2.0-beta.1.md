# 灵音 v1.2.0-beta.1 · 玻璃界面预览

本次为预发布版本，集中改进界面、触控反馈与小屏布局。

## 更新内容

- 重构推荐页：封面主卡、精简歌曲列表、横向歌单与热门歌曲。
- 新增浅色玻璃音符图标，统一导航、播放控件与操作按钮的玻璃材质。
- 增强按钮按压、回弹和选中状态过渡；支持减少动效与降低透明度。
- 播放模式改为应用内选择面板，与播放器和队列同步保存。
- 修复歌单操作栏、来源文字越界、安全区归零与小屏/横屏适配。
- 修复播放位置缓存不刷新造成的进度停滞。
- 优化媒体通知与封面异步更新；增加通知状态诊断和设置入口。
- 样式及字体随 APK 打包，避免外部样式服务不可用时界面异常。

## 安装说明

- 附件为调试签名的预览 APK，包名 `com.auramusic.app.preview`，名称「灵音预览」。
- 可覆盖本次开发期间安装的同签名「灵音预览」；可与正式版并存，数据独立。
- 原正式版签名暂不可用，本包不能覆盖升级正式版。请保留原应用及其数据。
- 不包含第三方音源，首次安装需自行配置。

## 已验证与限制

- 已在 vivo X200 Pro mini / OriginOS 6 验证安装、页面显示、歌单详情、播放/暂停/切歌及进度更新。
- 自动化覆盖五种界面尺寸、设置持久化、歌单边界及按压动画；Android 构建和 Lint 通过。
- 原子岛仍未确认恢复。本次移除了不符合文档类型的猜测通知载荷，标准媒体通知正常不代表系统会显示原子岛。
- 界面为 WebView 玻璃风格实现，不宣称与 Apple 原生渲染或帧率一致。

附件同时提供 SHA-256 校验文件。
