# 灵音 v1.3.1

本版重点优化播放页核心稳定性、手势交互与全屏视觉质感，彻底消除切歌与横屏痛点，带来全新软质 Q 弹液态玻璃视觉体验。

### 核心播放与交互体验优化
- **心跳时钟生命周期自愈**：修复息屏唤醒或切回前台后，播放进度轮询未自动恢复导致的卡死与停更问题；优化后台切歌时的异步网络保活机制。
- **歌词手势全域安全捕获**：修复滑动歌词滑出容器边缘或触发系统边缘手势时，触摸状态机死锁导致歌词永久停滚的 Bug。切歌时自动复位手势锁定态。
- **切歌即时乐观归零**：切歌第一帧立即将进度条与时间文本归零，消除换源解析期间上一曲尾部进度残留的停滞感。
- **横屏/车机一体化底盘重构**：严密锁定横屏全屏播放器视口，彻底消除横向模式下意外触发的纵向滚动条及进度条与背景画卷脱节分离的问题。

### 软质 Q 弹液态拟态视觉升级
- **动态流动环境光晕**：恢复底层彩色弥散流光，赋予背景柔和流动的呼吸感，彻底告别单调灰暗的生硬毛玻璃。
- **物理弹簧过冲回弹（Spring Rebound）**：引入非对称物理阻尼曲线，按下呈现水滴微形变，释放产生 Q 弹过冲抖动，操作极具生命力。
- **水珠张力漫反射微高光**：以弧面高光漫反射与复合内阴影取代死板的 1px 实线边框，视觉更温润、通透、高级。
