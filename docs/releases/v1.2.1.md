# 灵音 v1.2.1

## 蓝牙歌词

- 设置 → 系统播放新增“蓝牙歌词”，默认关闭，选择会保留。
- 参考 LX Music Mobile 的媒体信息方案独立实现：通过标准曲名字段向支持的蓝牙车机提供当前歌词，歌手字段保留歌曲信息。
- 原生播放服务负责歌词时间轴，锁屏、后台、拖动进度和切换音质均可继续同步。暂停、禁用和歌词空白时恢复歌曲信息。
- 修复迟到的歌曲、歌词和音质解析结果覆盖当前播放，以及切歌解析期间前后台同步回到旧歌曲的问题。
- 车机需要动态刷新蓝牙媒体信息；长安 2023 款糯玉米 205 尚未实车验证。详见[使用与兼容说明](../bluetooth-lyrics.md)。

## 音源管理

- 当前音源、文件/链接/源码导入、更新提示和移除确认统一为浅色液态玻璃样式，加入柔和按压与过渡。
- 调整小屏与横屏布局、长名称和描述换行，支持减少动效及降低透明度。
- 增加移除确认，补齐 Android 返回、Escape、焦点返回和导入忙态。移除音源保留歌单、收藏和队列。

## 安装

包名仍为 `com.salt.music`，桌面名称「灵音」，`versionCode=13`。使用与 v1.2.0 相同的固定发布签名，已安装正式 v1.2.0 可覆盖升级并保留数据。

同包名 debug 测试版签名不同，不能直接覆盖安装；不要直接卸载以免丢失本地数据。历史包名冲突与数据迁移说明见 [v1.2.0](v1.2.0.md)。

## 验证

26 项前端行为测试、8 项原生歌词时间轴测试、5 项音源管理测试、5 种通用 UI 视口以及搜索/音质/背景过渡回归通过。正式 APK 构建及 Android Lint 通过（无错误），签名指纹与 v1.2.0 一致。本次未连接真机或车机，硬件显示效果待实测。
