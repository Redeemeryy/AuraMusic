# 灵音 v1.4.2 · 后台媒体控制加固、切歌流畅度优化与播放列表样式修复

- **修复切出应用、锁屏页面与控制栏/导航栏无法切歌和暂停的问题**：
  - 通知栏动作改用 `PendingIntent.getForegroundService` 并为播放/暂停分配独立请求码，同时在 `onStartCommand` 中安全确保前台服务状态，防止切到后台后按钮点击被系统拦截。
  - 统一 `MediaControlPolicy` 状态机，显式接管耳机/锁屏/控制中心媒体按键，使缓冲期间按暂停/播放键能够立即暂停而非继续起播；并在切歌缓冲切换阶段保持 `STATE_BUFFERING` 与唤醒锁连贯，不再闪烁为暂停态或提前释放唤醒锁。
  - 修复 `MainActivity.onStop()` 在暂停/切歌加载期间冻结 WebView JS 以及系统手势返回直接销毁 Activity 导致 `MusicService` 与前端失联的问题；播放会话期间按系统返回优先后台保活（`moveTaskToBack`），并保持切歌与曲终连播稳定运行，仅暂停视觉装饰动画以节省功耗。
  - 若用户在等待音频直链解析过程中提前点击暂停，延迟返回的地址不再误触发自动起播。
- **修复播放页切歌卡顿与加载漏底闪烁**：
  - 为 `#fullPlayerOverlay` 与 `.player-artwork-backdrop` 锁定不透明深色合成画布与 `isolation: isolate`；移除会强迫 60fps 重采样背景的黑胶底座 `backdrop-filter`、冗余 `blur-3xl` 节点与播放器内 8 组高开销 SVG 位移滤镜；并将背景专辑封面动态模糊优化为轻量化合成与预解码封面平滑切换，消除加载瞬间穿底闪白与掉帧感。
- **修复播放页播放列表（`#queueOverlay`）与弹窗样式**：
  - 解除选择器冲突，完整恢复并升级播放列表抽屉、缩略图曲目行、当前曲目高亮及播放模式选择器/顶部灵动提示胶囊样式，适配 `320px` 小屏与横屏分栏抽屉。

## 安装与更新

正式包沿用 `com.salt.music` 和原发布签名。已安装 v1.4.1 的用户可直接通过应用内更新完成 APK 差分升级；其他版本可下载 `AuraMusic-v1.4.2.apk` 覆盖安装。

原生版本号为 21，内置网页版本为 6。
