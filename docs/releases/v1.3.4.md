# 灵音 v1.3.4 · 液态玻璃光学质感与歌词体验优化

- **Apple Liquid Glass 光学质感升级**：基于圆角有向距离场（SDF）与有限差分曲面法线重绘玻璃透镜位移贴图，实现凸面晶体边缘折射、高光轮廓与浮动控制层分离；叠加透镜贴图缓存与尺寸去重，提升滚动与切歌时的渲染流畅度。
- **多页面排版与交互细节优化**：为资料库新增与搜索页风格一致的分段胶囊切换栏；搜索栏支持吸顶固定与一键清空按钮；冷启动与缺图场景改用内联渐变黑胶 SVG 占位封面；并统一多页面无障碍标签、间距节奏与横屏/弹窗视觉层次。
- **未播放状态预加载歌词**：切入歌词页时无论歌曲是否已开始播放均立即加载并展示当前歌曲歌词（恢复上次播放曲目时亦不会误触发自动播放）；修复音频流解析缓慢或失败时歌词卡住的问题；未配置音源时给出明确提示，并在音源初始化完成后自动补全歌词。

## 安装与更新

正式包沿用 `com.salt.music` 和原发布签名。已有正式版可通过应用内更新，也可下载 `AuraMusic-v1.3.4.apk` 覆盖安装。使用 v1.3.3 正式包的用户可走 APK 差分更新，系统会在安装前请求确认。

原生版本号为 18，内置网页版本为 3。
