# 灵音 v1.4.0 · 全端 Apple Liquid Glass 重构与丝滑手势交互

- **底部与侧边晶透导航栏交互升级**：遵循 Apple iOS 26 Liquid Glass 先光学折射后轻柔模糊的设计原理，调整导航栏与迷你播放器的透镜滤镜链路并降低底层遮挡感，显著提升高亮选中胶囊的对比度与高光轮廓；支持竖屏横向按住拖拽、横屏左侧栏纵向按住拖拽，跟随手指产生液态水滴放大拉伸与边界阻尼回弹，并实时驱动主视图横向平滑滑动切换（发现 / 搜索 / 资料库 / 设置）。
- **播放页深色宝石氛围重塑**：重构全屏播放页背景，随专辑封面提取生成深邃饱和的宝石氛围渐变，配以通透荧光文字、晶透顶栏胶囊、蓝宝石黑胶唱片底座及微刻纹槽；强化 Apple Music Sing 聚光灯歌词焦点（未播放或暂无激活行时同样保持清晰可读），整合发光进度条、一体化控制胶囊及横屏分栏体验，并保留无透明高对比无障碍回退。
- **歌单详情页全屏液态玻璃**：引入随当前歌单封面实时联动的全屏柔焦氛围底图、滚动悬浮透明顶栏、晶莹封面头图卡、320px 小屏自适应操作按钮以及分组磨砂曲目容器，统一内容层与控制层的景深关系。
- **设置页与全局视觉一致性打磨**：重做设置页磨砂玻璃分组卡片、自包含玻璃开关及音质选中胶囊，优化离线图标裁切防溢出，并补充横竖屏手势导航拖拽回归测试。

## 安装与更新

正式包沿用 `com.salt.music` 和原发布签名。已有正式版可通过应用内更新，也可下载 `AuraMusic-v1.4.0.apk` 覆盖安装。使用 v1.3.4 正式包的用户可走 APK 差分更新，系统会在安装前请求确认。

原生版本号为 19，内置网页版本为 4。
