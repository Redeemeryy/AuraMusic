# 灵音 v1.2.0-beta.2 · 正式签名构建

本版沿用 beta.1 的玻璃界面、推荐页重构、浅色图标、按钮按压回弹、设置与播放进度修复，新增固定发布签名和可重复的本地签名构建流程。

- 播放队列重构为封面与歌曲信息列表，当前曲目淡色标记，简化冗余标签；支持删除和播放模式切换。
- 柔化播放页玻璃按钮的白色描边与阴影，降低边缘生硬感。

## 安装

- 下载 `AuraMusic-v1.2.0-beta.2.apk`：正式包名 `com.auramusic.app`，versionCode 10，非调试 release 构建。
- 可以与独立包名的「灵音预览」共存，数据独立；首次使用需自行配置音源。
- 如手机仍安装着不同签名的旧正式包名测试版，将不能直接覆盖；请先导出必要数据，不要盲目卸载。
- 从本版开始，后续正式包名的发行包使用同一发布密钥升级。
