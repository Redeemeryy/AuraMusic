# 灵音 v1.4.1 · 修复图标字体加载并补全图标变体支持

- **修复全端按钮与导航图标显示为字母的问题**：恢复 `Material Symbols Outlined` 离线 `@font-face`（`material-symbols.woff2`）字体规则及连字激活属性，移除临时文字裁切样式，确保导航栏、设置页、迷你播放器与播放页的全部矢量图标恢复正常渲染。
- **补全实心收藏图标与自动化防回归校验**：补充 `.material-symbols-outlined.fill-1` 的可变字体填充变体定义，并新增离线字体加载与单图标宽度自动化回归测试，防止后续样式重构遗漏图标字体声明。
