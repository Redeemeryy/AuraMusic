# 灵音 v1.3.3 · 液态玻璃与播放体验

- 底栏、横屏侧栏和迷你播放器会折射下方的页面内容。四个主菜单共用一枚随切换滑动、拉伸的选中胶囊，音质、播放模式和音源菜单从各自的按钮展开。支持减少动效和降低透明度。
- 用页面按钮、键盘回车或 Android 软键盘的搜索键提交后，键盘会收起，页面会跳到最新结果。
- 修复歌词偶发显示格式标签、短歌词误匹配和切歌后短暂显示上一首歌词的问题。
- 随机播放的下一首会避开当前曲，上一首回到本次队列里实际听过的歌曲。修复不同音源的同 ID 歌曲选错，以及删空队列后无法暂停的问题。

## 安装与更新

正式包沿用 `com.salt.music` 和原发布签名。已有正式版可通过应用内更新，也可下载 `AuraMusic-v1.3.3.apk` 覆盖安装。使用 v1.3.2 正式包的用户可走 APK 差分更新，系统会在安装前请求确认。

原生版本号为 17，内置网页版本为 2。完整的验证范围见[测试记录](https://github.com/Redeemeryy/AuraMusic/blob/v1.3.3/docs/2026-11-15-liquid-glass-qa.md)。
