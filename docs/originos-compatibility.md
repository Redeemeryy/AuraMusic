# OriginOS 音乐岛兼容性

v1.2.0 恢复项目历史包名 `com.salt.music`。在 vivo X200 Pro mini、OriginOS 6 构建 `PD2419B_A_16.1.13.1.W10`、音乐组件 `6.2.7.2` 上，已验证音乐岛显示封面及声波，展开后显示标题、歌手与进度，播放、暂停及切歌可用。

对照版本的 DEX 和网页资源完全相同，仅包名和显示名称不同：`com.auramusic.app` / `.preview` 未显示，历史包名显示。系统组件中的音乐岛名单包含历史包名而不包含前两者；最终通知发送之前也有包名判断。因此修改媒体通知字段或签名不能替代系统侧支持。

这只代表已测试设备和组件版本，不承诺其他 OriginOS 设备均可用，也不代表厂商歌词、收藏、循环或分页歌单等扩展全部实现。应用与 vivo、椒盐音乐无关联。

## 安装冲突与迁移

`com.salt.music` 同时是椒盐音乐的包名，两个应用无法同时安装；不要为安装灵音而直接卸载其他应用。此限制在 GitHub Release 中同步说明。

之前使用 `com.auramusic.app` 或 `.preview` 的灵音与本版可共存，但它们的数据各自独立，需要先备份、迁移。使用相同 `com.salt.music` 的调试测试版由于签名不同，无法直接覆盖升级为正式签名版。请保留旧应用，完成数据备份与迁移后再处理安装。

自有独立包名的长期方案仍需要厂商提供正式接入或开放系统支持。
