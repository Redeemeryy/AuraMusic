# 灵音 Liquid Glass 实施计划

**Goal:** 实现已批准的玻璃界面、布局适配与真实设置，并以真机证据排查原子岛。
**Architecture:** 保留 Kotlin/WebView；独立 preferences.js 管理偏好，app.js 负责业务同步；样式按内容/控制层组织。标准 MediaSession 与厂商兼容分开验证。
**Tech Stack:** Kotlin、Media3、原生 JavaScript、CSS、Node 测试、Gradle。
**Spec:** ../specs/2026-10-25-liquid-glass-design.md

## 约束
- 保留 com.auramusic.app 与用户数据；不卸载、不伪装第三方包名。
- 保留音源协议，原子岛实际显示与普通媒体通知分别报告。
- 中文交互、UTF-8；动画优先 transform/opacity，降低透明度和减少动效可持久化。
- 测试窄屏、横屏、键盘、大字体、离线资源；更新前核对签名。

## 任务
1. [ ] 设置：先写 Node 行为测试，验证损坏偏好回退、持久化、仅清历史；创建 preferences.js，接入 app.js 的播放模式统一更新、设置页控件与原生通知入口。
2. [ ] 视觉：替换重复玻璃与固定安全区规则，改造导航/播放器/设置；本地编译 Tailwind 并本地化图标。验证全部页面、弹层、多个尺寸与减少动效。
3. [ ] 媒体：定向读取真机/SystemUI 证据，验证通知状态、封面竞态、厂商字段协议与准入；只修复可证实的问题，增加可读取的诊断。
4. [ ] 构建：核对 JDK，准备缺失 SDK 34/Gradle；运行 JS 测试、语法检查、Android 构建与静态检查；签名允许时真机验证。
5. [ ] 审阅与交付：检查回归和差异，记录已通过/待验证内容，不自动发布。

## Review Focus
- 偏好存储异常：回退而不清空收藏或插件。
- 多入口播放模式：设置、队列、播放器保持一致。
- 异步封面回调：切歌后旧结果不可覆盖当前曲目。
- 小窗口/键盘：关闭与主要操作始终可访问。
- 通知权限关闭或厂商不接纳：状态真实，不误报原子岛已启用。
