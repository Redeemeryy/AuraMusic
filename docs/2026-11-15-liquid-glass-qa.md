# 灵音液态玻璃改版与测试记录

## 交付

- 本地预览包 `artifacts/AuraMusic-preview-LiquidGlass-20261115.apk`，应用名「灵音预览」，包名 `com.salt.music.preview`。在模拟器上验证了与正式版 `com.salt.music` 共存。
- 原生版本 1.3.2（16），内置网页版本 2。已验证 APK 签名和 23 个网页文件的 SHA-256，包内文件与工作区一致。
- APK SHA-256 `7ec1d4f85826bd91472bf25b4c8a9a86962d96f94cf920f754b29118dbef5085`。

## 改动

- 底栏、横屏侧栏和迷你播放器使用本地 SVG 位移图折射 WebView 背景。横屏发现页的封面可以延伸到侧栏后方。去掉全屏极光和逐行着色器，保留内容的封面与清晰列表。降低透明度时停用折射，使用高对比实色。
- 四个主菜单共用一枚选中胶囊，滑动时沿导航方向拉伸，连点从当前位置继续，旋转时跟随导航轴。播放模式、音质和音源菜单以触发位置为展开起点，关闭后归还焦点。减少动效时直接切换。
- 搜索键和页面按钮共用表单。有效搜索先收起键盘，再定位最新结果或失败提示。切换音源、清空和新查询可使旧结果失效。
- LRC、QRC、TTML 和旧时间线统一清理格式标记，保留唱词、时间轴与空白段。短歌词可正常显示，跨源回退核对歌曲与已知歌手。切歌加载期间显示新歌的加载状态，播放器与蓝牙共用清洗后的时间线。
- 随机下一曲避开当前曲，上一曲按本次队列中已开始播放的曲目回退。回退记录保存在当前页面会话，整队替换时重置。跨音源同 ID 曲目独立定位，删空队列后当前曲仍可暂停和继续，播完保持空队列。

## 回归记录

- 网页主套件 61 项通过，覆盖歌词和蓝牙时间线、连续切歌、音源身份、队列、更新和存储迁移。网页布局另验 320×640、347×754、393×852、800×360 和 1024×768。推荐、搜索与音质、动效、折射、队列、歌单编辑 14 项、音源管理 5 项通过。
- Chrome 用真实 DOM 背景做像素对比，关闭位移时有 3,050 个像素与开启状态不同。Android 模拟器对最终 APK 的系统截图做同样对比，有 33,835 个物理像素发生变化。确认连点、切换途中旋转、弹层焦点归还和减少动效。迷你播放器的进度线在胶囊边界内。
- 网易云公开歌单 `572164544` 实测导入 314/314 首，首曲及封面一致，无重复歌单卡片。
- Android 构建与 `lintDebug` 通过。原生单测 46 项通过，使用 JDK 17 直接运行 JUnit。当前 Windows 环境中 Gradle 单测进程无法加载已编译的测试类。
- Android 16 模拟器的 WebView 为 133.0.6943.137。通过实际 Gboard 按键提交英文，以及从键盘剪贴板粘贴中文后提交。每次发出一个请求，键盘收起，结果可见。模拟器的中文拼音语言包当时未下载完成。
- Android 16 模拟器使用本地 WAV 和可控音源数据，验证原生进度推进、歌词时间线清理和随机播放 A→C 后上一曲回 A。系统媒体浏览服务的两项绑定测试通过。

## 设备覆盖

- 模拟器可进入横屏并保留所选菜单。后续复测时，Windows 记录了模拟器进程 `qemu-system-x86_64-headless.exe` 的 `0xc0000005` 崩溃。随后用于重装预览包并补测后台媒体键的命令被执行策略拒绝。前后台连续播放与后台系统切歌尚未完成设备验证，浏览器媒体事件回归与 Android 媒体服务绑定测试通过。
